# Database

Postgres is required for web authentication, sessions, email tokens, and chat
history. The data pipeline artifacts remain file-based under `data/`.

## Compose

Start Postgres only:

```bash
scripts/docker/compose.sh db up
```

Run migrations:

```bash
scripts/docker/compose.sh db migrate
```

Open psql:

```bash
scripts/docker/compose.sh db shell
```

The `dev` and `inference` workflows include `docker/compose/db.yml`
automatically and run `alembic upgrade head` before starting FastAPI.

## Schema Overview

- `users`: account email, password hash, active/verified flags.
- `sessions`: hashed session tokens, expiry, revocation, user agent, IP.
- `email_verification_tokens`: hashed single-use verification tokens.
- `password_reset_tokens`: hashed single-use password reset tokens.
- `conversations`: per-user chat containers with soft delete.
- `messages`: user and assistant messages plus route/metric metadata and full
  assistant response JSON.
- `auth_events`: register/login/logout/reset audit trail.

All primary keys are UUID strings. Timestamps are UTC and timezone-aware.

## Migrations

Alembic config lives at `alembic.ini`; migration scripts live under
`webapp/backend/migrations/`.

Create a new migration after changing SQLAlchemy models:

```bash
DATABASE_URL=postgresql+asyncpg://finedgar:password@localhost:5432/finedgar \
  alembic revision --autogenerate -m "describe change"
```

Review autogenerated migrations before committing them, then apply:

```bash
alembic upgrade head
```

Inside Docker, prefer:

```bash
scripts/docker/compose.sh db migrate
```

## Backup

```bash
scripts/docker/compose.sh db up
docker compose --project-directory . \
  -f docker/compose/base.yml \
  -f docker/compose/db.yml \
  exec -T postgres pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB" \
  > outputs/finedgar_postgres_backup.sql
```

## Restore

Restore into an empty initialized database:

```bash
scripts/docker/compose.sh db up
docker compose --project-directory . \
  -f docker/compose/base.yml \
  -f docker/compose/db.yml \
  exec -T postgres psql -U "$POSTGRES_USER" "$POSTGRES_DB" \
  < outputs/finedgar_postgres_backup.sql
```

## Local Reset

This deletes all web users, sessions, tokens, conversations, and messages:

```bash
scripts/docker/compose.sh inference down
docker volume rm finedgar_postgres-data
```

It does not delete EDGAR corpus files in `data/`, model files in `model/`, or
evaluation outputs.

## Retention Notes

Conversation deletion is soft-delete via `deleted_at`. Message rows remain for
that conversation. A future retention job can hard-delete soft-deleted
conversations older than a chosen retention window.
